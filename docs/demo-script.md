# Сценарий демонстрации (5–7 минут)

| Время | Действие | Что показать |
|---|---|---|
| 0:00 | `npm start`, открыть http://localhost:3000 | Запуск без установки зависимостей |
| 0:30 | Вход `director / director2026` | «Пульс компании»: 17 KPI, план/факт/прогноз, цвет статуса, блок «Критические отклонения» |
| 1:15 | Кнопка «i» у KPI «Брак / перепечатка» | Формула, источники (ERP), время обновления файла и дата последних данных |
| 1:45 | Сменить период на «Год», продукт «календарь» | Все карточки и графики пересчитались, прогноз мощности остаётся |
| 2:15 | Клик по красному KPI «Брак» → разрез «Станок» | Объяснение «Главный вклад: Станок №14», переключение разрезов «Причина брака», «Продукт» |
| 3:00 | Клик по станку → записи → номер заказа | Сквозная карточка: CRM-заказ → клиент → ERP производство → смена и оператор (HR) → дефекты → оплаты |
| 3:45 | «Создать решение» | Поля предзаполнены контекстом; заполнить действие, ответственного, срок → «Создать». Попробовать пустую форму — ошибки на русском |
| 4:30 | Выйти, войти снова → «Реестр решений» | Решение на месте; сменить статус «в работе» → история изменений |
| 5:00 | Выйти, войти `sales / sales2026` | Видны только продажи; баннер о скрытых подразделениях; производство и финансы недоступны (403 при прямом запросе) |
| 5:30 | Войти `analyst / analyst2026` → «Кабинет аналитика» | Свежесть источников, разорванные связи, дубли, расхождение сверки за 2025-08 |
| 6:00 | «Журнал действий» | Входы, просмотры, создание решения, отказы в доступе |
| 6:20 | Остановить сервер (Ctrl+C) и нажать любой фильтр | Баннер «Нет связи с сервером», интерфейс не завис; запустить сервер — «Связь восстановлена» |
| 6:45 | «Прогноз спроса и мощности» (директор / prod) | 8 недель, дефицит с 16.11.2026 из-за плановых ремонтов и сезона |
